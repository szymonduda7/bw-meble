# BWKotwieja-Meble

Strona wizytówka producenta mebli na wymiar w Tarnowie (index.html + uslugi.html).

- `index.html`: hero z kolażem trzech zdjęć realizacji, usługi, opinie jako argumenty, darmowa wycena projektu, galeria realizacji z lightboxem, opinie z Oferteo, kontakt z mapą i godzinami
- `uslugi.html`: karty usług (kuchnie, garderoby i szafy, pokojowe, biurowe, sklepowe, łazienkowe)
- `styles.css`, `main.js`: wspólne style i skrypty
- `images/*.webp`: zdjęcia realizacji (maks. 1600 px)

Tailwind CSS i ikony Lucide z CDN, fonty Familjen Grotesk + Instrument Sans.
